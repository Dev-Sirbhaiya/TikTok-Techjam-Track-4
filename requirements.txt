# Dependencies for the TechJam Conversational Search starter agent + local evaluator.
#
# The participant repo (external/techjam-conversational-search) ships no
# requirements.txt / pyproject.toml / setup.py. Its starter/agent.py and
# evaluator/local_evaluator.py import only Python standard library modules
# (json, re, sqlite3, argparse, random, statistics, uuid, collections,
# pathlib) -- confirmed by inspecting both files directly.
#
# Python 3.10+ is required (README recommendation). Tested here with
# Python 3.13.7. No third-party packages are required to run the starter
# agent or the local evaluator as of participant-kit release
# (commit 9a35be51780ff1caf89eceaabca34259e946f40f).
#
# This file is intentionally left with no pinned packages. If your own
# agent implementation adds dependencies (e.g. an LLM client SDK), add
# them here and re-run `pip freeze > requirements-freeze.txt`.
